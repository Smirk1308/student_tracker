# Reference experience study

Studied in a real browser on 13 Nov 2026. This records experience patterns only, not reusable source or assets.

- Loader: compact logo/loading state before an immersive scene.
- Sequence: hero mission statement, a single prominent CTA, then progress-led storytelling.
- Scene: purple space field, centered white display type, orbit/debris depth, small persistent header.
- Motion: calm cinematic floating and staged copy; interactions use short soft transitions.
- Hover: restrained CTA elevation/scale; progress indicator provides orientation.
- Responsive: centered hierarchy and compact header preserve the primary CTA.

Syllabus Wallah adapts the feeling with original navy/violet/amber flight-path graphics, Devanagari-inspired logo, own copy and lightweight CSS/SVG—not their branding, imagery, or code.
