# New surprise procedure

1. Run grill-me for at most three one-at-a-time decisions and add them to `PLAN.md`.
2. Decide whether it belongs in one new core rule, one new feature, or both.
3. Add at most three tasks: new file(s), tests, and one registry line. Do not rewrite existing paths.
4. Builder implements tasks in order and verifies the full judge path again.
